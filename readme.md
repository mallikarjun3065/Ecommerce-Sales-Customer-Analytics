# E-Commerce Sales Analytics

An end-to-end e-commerce analytics project using the Olist dataset. It includes
Python scripts to clean the source CSV files, optional MySQL loading and SQL
analysis, and a Power BI report focused on sales and customer trends.

## Project contents

```text
.
├── data/
│   ├── raw/                 # Original Olist CSV files
│   └── cleaned/             # CSV files generated by the cleaning scripts
├── powerbi/
│   ├── sales.pbix           # Power BI report
│   └── *.png                # Report screenshots
├── python/
│   ├── data_cleaning.py     # Cleans orders and adds date/delivery fields
│   ├── clean_other_data.py  # Cleans customers, items, products, payments, reviews
│   └── import_all.py        # Loads cleaned CSVs into MySQL
├── sql/
│   └── analysis_queries.sql # Example MySQL sales and customer analyses
└── requirements.txt
```

## Analysis included

- Delivered-order sales, order count, and average order value
- Monthly sales trends
- Top product categories by sales
- Repeat customer counts and percentage
- Payment method performance
- Power BI views for sales over time, product categories, and order status

The report also includes headline sales, order, customer, and average-order-value
cards, plus a date-range filter. Currency display is configured in the report.

## Requirements

- Python 3.9 or later
- MySQL Server (only needed for the database import and SQL analysis)
- Power BI Desktop (to open or refresh the `.pbix` report)

Install the Python dependencies from the project root:

```bash
python -m venv .venv
```

Activate the environment, then install dependencies:

```powershell
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

```bash
# macOS/Linux
source .venv/bin/activate
pip install -r requirements.txt
```

## Prepare the cleaned data

Run both cleaning scripts from the project root. They read from `data/raw/` and
write their results to `data/cleaned/`.

```bash
python python/data_cleaning.py
python python/clean_other_data.py
```

The orders script parses timestamp columns, removes duplicate or incomplete
order records, and adds purchase year/month and delivery-delay fields. The
second script removes exact duplicate rows from the other five datasets and
converts applicable price and payment columns to numeric values.

## Optional: load data into MySQL

1. Create an empty MySQL schema/database and ensure the MySQL server is running.
2. Prepare the cleaned CSVs using the steps above.
3. Run the importer from the project root:

   ```bash
   python python/import_all.py
   ```

4. Enter the MySQL host, port, username, password, and schema name when
   prompted. The password is requested securely.

The importer creates tables named `customers`, `order_items`, `order_payments`,
`order_reviews`, `orders`, and `products`. **Existing tables with these names
in the selected schema are replaced.** Use a disposable or correctly backed-up
schema if you need to preserve existing tables.

## Run the SQL analyses

Open `sql/analysis_queries.sql` in a MySQL client connected to the schema
populated above, then run the queries. The queries expect the table names and
columns created by the importer.

## Open the Power BI report

Open [`powebi/sales.pbix`](powebi/sales.pbix) in Power BI Desktop. If prompted
to configure a data source, connect it to your data and refresh the report.
Screenshots of the report are included in the same folder.

## Data files

The raw and cleaned CSVs are included in the repository under `data/raw/` and
`data/cleaned/`. The cleaning scripts can regenerate the cleaned files from
the raw data.
